# kubernetic

EKS Auto Mode cluster, reconciled by Flux from `clusters/kubernetic`.

EKS Auto Mode manages compute (Karpenter), networking (VPC CNI), storage
(EBS CSI), load balancing and Pod Identity, so none of those are installed here.

## Bootstrap Flux (one time)

With `kubectl` pointed at the cluster and a GitHub PAT in `GITHUB_TOKEN`:

```sh
flux bootstrap github \
  --owner=cdirubbio \
  --repository=homelab \
  --branch=main \
  --path=clusters/kubernetic \
  --personal
```

This commits `clusters/kubernetic/flux-system/` and from then on Flux applies
every manifest under `clusters/kubernetic/`.

## Layout

| Path | What |
|------|------|
| `flux-system/` | Generated by `flux bootstrap`. Do not edit. |
| `builds/` | Kaniko container builds pushing to ECR (see `builds/README.md`) |
